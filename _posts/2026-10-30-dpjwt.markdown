This blog post will guide you to implement a Datapower Service to communicate with a backend server that is protected using the following mechanisms:

- JWT (JSON Web Token) ---> With JWS (JSON Web Signature) and JWE(JSON Web Encryption)
- MTLS validation

The architecture will implement a IBM Datapower Multi-protocol gateway service to generate a signed and encrypted JWT to be used to make the call to the backend application. Also Datapower will send the corresponding certificates to the backend due to the MTLS requirement.

The following diagram represents a high level architecture of this POT

![Image](/assets/jwt/18.png){:width="1500px" height="500px"}
