This blog post will guide you to implement a Datapower Service to communicate with a backend server that is protected using the following mechanisms:

- JWT (JSON Web Token) ---> With JWS (JSON Web Signature) and JWE(JSON Web Encryption)
- MTLS validation

The architecture will implement a IBM Datapower Multi-protocol gateway service to generate a signed and encrypted JWT to be used to make the call to the backend application. Also Datapower will send the corresponding certificates to the backend due to the MTLS requirement.

### C. Create and Configure the Datapower Service

- Switch to the newly created application domain

![Image](/assets/jwt/16.png){:width="500px" height="400px"}

- Use the left menu to search for "crypto tools" and click it

![Image](/assets/jwt/11.png){:width="800px" height="500px"}

- Create New self-signed certificates to be used in your service, using the following values:
  - Country name (C): US
  - State or province (ST): TX
  - Locality (L): WL
  - Organization (O): FXN
  - Organizational unit (OU): FXN
  - Common name (CN) (Required): datapower
  - Key type: RSA
  - RSA key length (Required): 2048 bits
  - Hash algorithm (Required): SHA-256
  - Validity period: 365
  - Password alias: (none)
  - Export private key: ON
  - Generate self-signed certificate ON
  - Export self-signed certificate ON
  - Generate objects ON
  - Leave all other values by default

![Image](/assets/jwt/12.png){:width="500px" height="400px"}
![Image](/assets/jwt/13.png){:width="500px" height="400px"}

- Click "Submit" to create the certificates

![Image](/assets/jwt/14.png){:width="500px" height="400px"}

- Click "Confirm" to proceed

![Image](/assets/jwt/15.png){:width="800px" height="200px"}

- You should see the confirmation message

![Image](/assets/jwt/17.png){:width="800px" height="200px"}
